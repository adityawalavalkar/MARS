# Jezero preprocessing (Phase 1)
Run from the MARS-NAV folder (needs: numpy scipy rasterio pyshp pillow matplotlib):

    pip install rasterio pyshp pillow matplotlib scipy
    python backend/scripts/preprocess_jezero.py --raw <uploads dir> --geo <geology shp dir> --nom <MARS nomenclature dir>

Outputs
- frontend/public/jezero/: hillshade/slope/elevation/thermal_inertia/crism_minerals PNG overlays (display, 1/3 res for DEM products), geology_units.geojson, nomenclature.json, science_targets.json (adds nearest CRISM class + DEM elevation), manifest.json (exact bounds S,W,N,E).
- data/processed/jezero/: 512x512 mesh JSON; full-resolution slope/roughness/aspect/dem/surface-unit/unit-cost .npy (git-ignored, regenerated by the script; used by the Phase 2 router).
- Editable assumptions: data/config/science_targets.json, data/config/unit_hazard_costs.json (all unit costs and the suit slope limit are ASSUMPTIONS).

Notes: slope = Horn, 20 m pixel; roughness = std of slope in 3x3; pixels touching DEM nodata are masked. Leaflet ImageOverlay is Mercator, so equirectangular overlays are stretched linearly in latitude (error <0.1% over this 1.5 deg area). Hazard here = DEM slope/roughness + ASSUMED unit costs: "derived hazard, not measured rock abundance". Thermal inertia is display-only.
